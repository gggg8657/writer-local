name: condolence
title: 조의 문구
category: 경조사
description: 부고에 보내는 위로 메시지·조화 리본
outputs: 3
inputs:
  - key: to
    label: 상주 (이름·직함)
    type: text
  - key: deceased
    label: 고인과 상주의 관계
    type: select
    options: [부친, 모친, 조부, 조모, 배우자, 장인·장모, 형제자매]
  - key: relation
    label: 나와 상주의 관계
    type: select
    options: [같은 부서 동료, 상사, 부하 직원, 타 부서 지인, 외부 협력기관]
  - key: use
    label: 쓰임
    type: select
    options: [메신저 한 줄, 조화 리본, 부의금 봉투·카드]
---
조의 문구를 쓴다. 절제된 어조, 종교색 없이. "메신저 한 줄"은 1~2문장(삼가 고인의 명복을 빕니다 류의 정형구 + 상주를 향한 한 문장), "조화 리본"은 정형구만(예: 삼가 고인의 명복을 빕니다 / 謹弔), "봉투·카드"는 2~3문장. 위로가 설교가 되지 않게.
