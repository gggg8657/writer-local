title: 경조사 축하 문구
category: 경조사
description: 결혼·출산·승진·정년 축하 메시지 (화환 리본·경조금 봉투·메신저용)
outputs: 3
inputs:
  - key: event
    label: 경사
    type: select
    options: [결혼, 출산, 승진, 정년퇴임, 전직·영전, 개업·개소, 자녀 입학·졸업]
  - key: to
    label: 받는 분 (이름·직함)
    type: text
    placeholder: 예) 김○○ 선임연구원
  - key: relation
    label: 나와의 관계
    type: select
    options: [같은 부서 동료, 상사, 부하 직원, 타 부서 지인, 외부 협력기관]
  - key: use
    label: 쓰임
    type: select
    options: [메신저 한 줄, 카드·봉투 문구, 화환 리본]
---
축하 문구를 쓴다. "메신저 한 줄"은 1~2문장, "카드·봉투 문구"는 3~4문장, "화환 리본"은 10자 안팎 정형구 + 보내는 이 표기 자리(○○○ 드림). 관계에 맞는 거리감(상사에게는 격식, 동료에게는 따뜻하게). 3안은 어조를 조금씩 달리.
